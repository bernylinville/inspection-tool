# CMDB 资产管理平台 - 产品需求文档

> 版本：v1.0
> 创建日期：2026-01-12
> 基于：巡检工具 v0.5.0

---

## 1. 项目背景

### 1.1 现状问题

当前运维团队面临以下挑战：

| 问题               | 影响                                                          |
| ------------------ | ------------------------------------------------------------- |
| **资产信息分散**   | 主机信息在 N9E、监控数据在 VM、告警在 FlashDuty，缺乏统一视图 |
| **巡检手动触发**   | 依赖 CLI 工具和人工调度，无法 Web 化管理和查看历史            |
| **无业务拓扑**     | 资产与业务应用的关系不明确，故障定位困难                      |
| **中间件管理缺失** | MySQL、Redis、Nginx、Tomcat、ES 实例无统一管理入口            |

### 1.2 建设目标

构建一个**轻量级资产管理平台**，作为运维团队的统一入口，**聚合而非替代**现有系统。

## 2. 目标用户

| 角色                 | 核心诉求                     |
| -------------------- | ---------------------------- |
| **运维工程师 (SRE)** | 资产查看、巡检触发、告警聚合 |

## 3. 核心功能（P0 - 必须实现）

### 3.1 资产管理

| 功能           | 说明                                           |
| -------------- | ---------------------------------------------- |
| 主机资产 CRUD  | 从 N9E 同步主机元信息（OS、CPU、内存、IP）     |
| 中间件实例管理 | MySQL、Redis、Nginx、Tomcat、ES 实例发现与管理 |
| 资产同步       | 定时从 N9E 同步主机，从 VM 发现中间件实例      |

### 3.2 数据聚合展示

| 功能     | 数据来源                              | 说明             |
| -------- | ------------------------------------- | ---------------- |
| 实时监控 | VictoriaMetrics `/api/v1/query`       | **透传**，不存储 |
| 历史趋势 | VictoriaMetrics `/api/v1/query_range` | **透传**，不存储 |
| 告警展示 | FlashDuty Open API                    | **只读**，不推送 |

### 3.3 巡检管理

| 功能         | 说明                                   |
| ------------ | -------------------------------------- |
| Web 触发巡检 | 调用现有 CLI 工具                      |
| 历史报告查看 | 报告存储在文件系统，元数据存储在数据库 |

### 3.4 权限控制

| 功能      | 说明                               |
| --------- | ---------------------------------- |
| 用户认证  | JWT + 密码登录                     |
| RBAC 权限 | admin / operator / viewer 三级角色 |

## 5. 明确不做（Scope 边界）

> **核心原则：CMDB 是资产管理平台，不是监控/告警平台。**

| 不做的事                   | 理由                   | 正确做法                        |
| -------------------------- | ---------------------- | ------------------------------- |
| **监控数据采集/存储**      | Categraf + VM 已实现   | 透传 VM 查询                    |
| **告警规则配置/触发/推送** | N9E + FlashDuty 已实现 | 只读 FlashDuty API              |
| **历史监控数据存储**       | VM 本身存储历史数据    | 直接查 VM `/api/v1/query_range` |
| **ClickHouse/时序数据库**  | 无需额外存储监控数据   | N/A                             |
| **告警通知/升级/认领**     | FlashDuty 已实现       | 只查看，不操作                  |
| **配置推送/变更管理**      | 超出 CMDB 范畴         | 使用专门的配置管理工具          |
| **日志采集/分析**          | 超出 CMDB 范畴         | 使用日志平台                    |
| **自动化运维/编排**        | 超出 CMDB 范畴         | 使用运维编排工具                |

## 6. 技术约束

### 6.1 外部系统（只读集成）

| 外部系统        | 接口                                            | 调用方式     | 写入     |
| --------------- | ----------------------------------------------- | ------------ | -------- |
| N9E             | `/api/n9e/targets`                              | 主机同步     | **只读** |
| VictoriaMetrics | `/api/v1/query`, `/api/v1/query_range`          | 监控数据透传 | **只读** |
| FlashDuty       | `/open-api/v1/alerts`, `/open-api/v1/incidents` | 告警展示     | **只读** |
| CLI 巡检工具    | 命令行调用                                      | 巡检执行     | -        |

### 6.2 技术选型

| 层级   | 技术栈                              |
| ------ | ----------------------------------- |
| 后端   | Go 1.25 + Gin + GORM + Casbin       |
| 前端   | Vue 3 + Vite + Vben Admin + ECharts |
| 数据库 | PostgreSQL 14+                      |
| 缓存   | Redis 6+                            |
| 部署   | 单二进制 (Go embed) 或 Docker       |

### 6.3 代码复用

复用现有巡检工具的以下模块：

| 模块       | 复用方式                    |
| ---------- | --------------------------- |
| N9E Client | **直接引用** - pkg/n9e      |
| VM Client  | **直接引用** - pkg/vm       |
| Model 层   | **参考复用** - 数据模型     |
| Evaluator  | **参考复用** - 健康评分逻辑 |

## 7. 非功能需求

### 7.1 性能要求

| 指标         | 要求                        |
| ------------ | --------------------------- |
| 页面加载时间 | < 2 秒                      |
| API 响应时间 | < 500ms（不含外部调用）     |
| 支持资产规模 | 500+ 主机，1000+ 中间件实例 |
| 并发用户数   | 50+                         |

### 7.2 安全要求

| 要求       | 说明                         |
| ---------- | ---------------------------- |
| 认证       | JWT Token，过期时间 24h      |
| 密码       | bcrypt 加密存储              |
| 权限       | RBAC，最小权限原则           |
| 审计       | 关键操作记录审计日志         |
| Token 管理 | N9E/FlashDuty Token 加密存储 |

### 7.3 可维护性

| 要求       | 说明                               |
| ---------- | ---------------------------------- |
| 日志       | 结构化日志 (zerolog)，支持级别配置 |
| 健康检查   | `/health` 端点                     |
| 配置管理   | YAML 配置 + 环境变量覆盖           |
| 数据库迁移 | 版本化迁移脚本                     |

## 10. 附录：数据模型概览

```sql
-- 核心实体
projects          -- 项目
applications      -- 业务应用
hosts             -- 主机资产
mysql_instances   -- MySQL 实例
redis_instances   -- Redis 实例
nginx_instances   -- Nginx 实例
tomcat_instances  -- Tomcat 实例
elasticsearch_clusters  -- ES 集群

-- 巡检相关
inspection_jobs   -- 巡检任务记录

-- 权限相关
users             -- 用户
roles             -- 角色
permissions       -- 权限
user_roles        -- 用户-角色关联
role_permissions  -- 角色-权限关联
```

详细表结构见 [architecture.md](./architecture.md) 数据库设计章节。
