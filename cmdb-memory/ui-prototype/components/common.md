# 通用组件规范

> 基于 vue-vben-admin 框架

---

## 1. 页面布局模板

### 1.1 标准布局结构

```
┌─────────────────────────────────────────────────────────────────┐
│ [Logo]  面包屑导航                         [搜索] [通知] [用户] │
├────────┬────────────────────────────────────────────────────────┤
│        │  ┌─────────────────────────────────────────────────┐   │
│ 侧边栏 │  │                   内容区域                       │   │
│        │  │                                                 │   │
│ - 菜单1│  │                                                 │   │
│ - 菜单2│  │                                                 │   │
│ - 菜单3│  │                                                 │   │
│        │  └─────────────────────────────────────────────────┘   │
└────────┴────────────────────────────────────────────────────────┘
```

### 1.2 组件说明

| 区域 | 组件 | 说明 |
|------|------|------|
| 顶部导航 | LayoutHeader | Logo、面包屑、搜索、通知、用户信息 |
| 侧边栏 | LayoutSider | 菜单树，支持折叠 |
| 内容区 | LayoutContent | 多标签页 + 页面内容 |
| 多标签 | MultipleTab | 页面标签切换 |

## 2. 列表页模板

### 2.1 布局结构

```
┌─────────────────────────────────────────────────────────────────┐
│  页面标题                                          [新增] [导出] │
├─────────────────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ [筛选字段1] [筛选字段2] [筛选字段3]    [查询] [重置]    │    │
│  └─────────────────────────────────────────────────────────┘    │
├─────────────────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ □ | 列1    | 列2    | 列3    | 列4    | 操作           │    │
│  ├─────────────────────────────────────────────────────────┤    │
│  │ □ | 数据1  | 数据2  | 数据3  | 数据4  | [编辑] [删除]  │    │
│  │ □ | 数据1  | 数据2  | 数据3  | 数据4  | [编辑] [删除]  │    │
│  │ □ | 数据1  | 数据2  | 数据3  | 数据4  | [编辑] [删除]  │    │
│  └─────────────────────────────────────────────────────────┘    │
├─────────────────────────────────────────────────────────────────┤
│  共 100 条  [<] [1] [2] [3] ... [10] [>]    每页 [20] 条        │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 核心组件

| 组件 | 用途 | 配置要点 |
|------|------|----------|
| BasicTable | 数据表格 | columns, dataSource, pagination, rowSelection |
| BasicForm | 筛选表单 | schemas, labelWidth, showAdvancedButton |
| TableAction | 操作按钮 | actions[], dropDownActions[] |
| useTable | 表格Hook | api, columns, formConfig, fetchSetting |

### 2.3 代码示例

```typescript
// 表格配置
const [registerTable] = useTable({
  api: getListApi,
  columns: tableColumns,
  formConfig: {
    schemas: searchFormSchema,
    labelWidth: 80,
  },
  useSearchForm: true,
  showTableSetting: true,
  bordered: true,
  actionColumn: {
    width: 120,
    title: '操作',
  },
});
```

## 5. 状态标签规范

### 5.1 Tag 颜色映射

| 状态类型 | 颜色 | 示例 |
|----------|------|------|
| 成功/在线/启用 | green | online, active, completed |
| 警告 | orange | warning |
| 错误/离线/禁用 | red | offline, inactive, failed, critical |
| 信息/进行中 | blue | info, running, pending |
| 默认 | gray | - |

### 5.2 代码示例

```typescript
const statusMap = {
  online: { color: 'green', text: '在线' },
  offline: { color: 'red', text: '离线' },
  active: { color: 'green', text: '启用' },
  inactive: { color: 'default', text: '禁用' },
};
```
