## 2. 数据字段需求

| 字段名 | 类型 | 说明 | 来源API |
|--------|------|------|---------|
| id | number | 实例ID | GET /api/v1/mysql-instances |
| address | string | 地址 | GET /api/v1/mysql-instances |
| version | string | 版本 | GET /api/v1/mysql-instances |
| cluster_mode | string | 集群模式 | GET /api/v1/mysql-instances |
| host_id | number | 所属主机 | GET /api/v1/mysql-instances |
| status | string | 状态 | GET /api/v1/mysql-instances |
