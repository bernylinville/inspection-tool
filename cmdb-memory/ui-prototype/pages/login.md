## 2. 组件说明

| 组件 | 类型 | 说明 |
|------|------|------|
| Logo | Image | 平台 Logo |
| 标题 | Text | "CMDB 资产管理平台" |
| 用户名输入框 | Input | 必填，3-50字符 |
| 密码输入框 | Input.Password | 必填，8位以上 |
| 记住我 | Checkbox | 可选，延长Token有效期 |
| 登录按钮 | Button | type=primary, 提交表单 |

---

## 3. 数据字段需求

| 字段名 | 类型 | 必填 | 说明 | 来源API |
|--------|------|------|------|---------|
| username | string | 是 | 用户名 | POST /api/v1/auth/login |
| password | string | 是 | 密码 | POST /api/v1/auth/login |

---

## 4. 交互流程

1. 用户输入用户名和密码
2. 点击登录按钮
3. 前端验证表单
4. 调用 POST /api/v1/auth/login
5. 成功：存储 Token，跳转 /dashboard
6. 失败：显示错误提示

---

## 5. API 依赖汇总

| API | 方法 | 用途 |
|-----|------|------|
| /api/v1/auth/login | POST | 用户登录 |
