---

## 2. 数据字段需求

| 字段名 | 类型 | 说明 | 来源API |
|--------|------|------|---------|
| id | number | 应用ID | GET /api/v1/applications |
| name | string | 应用名称 | GET /api/v1/applications |
| code | string | 应用编码 | GET /api/v1/applications |
| project_id | number | 所属项目ID | GET /api/v1/applications |
| owner | string | 负责人 | GET /api/v1/applications |
| status | string | 状态 | GET /api/v1/applications |

---

## 3. API 依赖汇总

| API | 方法 | 用途 |
|-----|------|------|
| /api/v1/applications | GET | 获取应用列表 |
| /api/v1/applications | POST | 创建应用 |
| /api/v1/applications/:id | PUT | 更新应用 |
| /api/v1/applications/:id | DELETE | 删除应用 |
| /api/v1/projects | GET | 获取项目下拉 |
