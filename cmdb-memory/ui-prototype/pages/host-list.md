## 2. 数据字段需求

| 字段名 | 类型 | 说明 | 来源API |
|--------|------|------|---------|
| id | number | 主机ID | GET /api/v1/hosts |
| ident | string | 标识符 | GET /api/v1/hosts |
| hostname | string | 主机名 | GET /api/v1/hosts |
| ip | string | IP地址 | GET /api/v1/hosts |
| os | string | 操作系统 | GET /api/v1/hosts |
| cpu_cores | number | CPU核数 | GET /api/v1/hosts |
| memory_total | number | 内存总量 | GET /api/v1/hosts |
| status | string | 状态 | GET /api/v1/hosts |
| last_sync_at | datetime | 同步时间 | GET /api/v1/hosts |

---

## 3. API 依赖汇总

| API | 方法 | 用途 |
|-----|------|------|
| /api/v1/hosts | GET | 获取主机列表 |
| /api/v1/hosts/sync | POST | 从N9E同步 |
| /api/v1/hosts/:id | DELETE | 删除主机 |
