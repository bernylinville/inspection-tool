---

## 2. 数据字段需求

| 字段名 | 类型 | 说明 | 来源API |
|--------|------|------|---------|
| host_id | number | 主机ID | GET /api/v1/hosts |
| metric | string | 指标名称 | 前端配置 |
| time_range | string | 时间范围 | 前端输入 |
| query | string | PromQL | GET /api/v1/monitor/query |
