# Nginx 实例列表

> 路由: /assets/middleware/nginx

---

## 1. 页面布局

```
┌─────────────────────────────────────────────────────────────────┐
│  Nginx 实例管理                                                 │
├─────────────────────────────────────────────────────────────────┤
│  [关键字____] [状态▼] [所属主机▼]         [查询] [重置]         │
├─────────────────────────────────────────────────────────────────┤
│  □ | 实例地址 | 版本 | 状态 | 配置路径 | Worker数 | 所属主机 | 操作 │
│  ─────────────────────────────────────────────────────────────  │

├─────────────────────────────────────────────────────────────────┤
│  共 30 条  [<] [1] [2] [>]    每页 [20] 条                      │
└─────────────────────────────────────────────────────────────────┘
```

---

## 2. 组件说明

| 组件 | 类型 | 说明 |
|------|------|------|
| 筛选表单 | BasicForm | 关键字、状态、所属主机 |
| 数据表格 | BasicTable | Nginx 实例列表 |

---

## 3. 数据字段需求

| 字段名 | 类型 | 说明 | 来源API |
|--------|------|------|---------|
| id | number | 实例ID | GET /api/v1/nginx |
| address | string | 实例地址 | GET /api/v1/nginx |
| version | string | 版本 | GET /api/v1/nginx |
| status | string | 状态 | GET /api/v1/nginx |
| config_path | string | 配置路径 | GET /api/v1/nginx |
| worker_processes | number | Worker进程数 | GET /api/v1/nginx |
| host_id | number | 所属主机 | GET /api/v1/nginx |

---

## 4. 交互流程

1. 页面加载 → 调用 GET /api/v1/nginx
2. 输入关键字或筛选条件 → 点击查询 → 重新拉取列表
3. 点击删除 → 确认弹窗 → DELETE /api/v1/nginx/:id
4. 点击详情 → 跳转实例详情页（如有）

---

## 5. API 依赖汇总

| API | 方法 | 用途 |
|-----|------|------|
| /api/v1/nginx | GET | 获取实例列表 |
| /api/v1/nginx/:id | DELETE | 删除实例 |
