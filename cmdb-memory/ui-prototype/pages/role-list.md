# 角色管理

> 路由: /system/roles

---

## 1. 页面布局

```
┌─────────────────────────────────────────────────────────────────┐
│  角色管理                                         [新增角色]    │
├─────────────────────────────────────────────────────────────────┤
│  □ | 角色名称 | 描述 | 权限数 | 用户数 | 操作                 │
│  ─────────────────────────────────────────────────────────────  │
│  □ | 管理员 | 全量权限 | 32 | 5 | [编辑][删除]               │
├─────────────────────────────────────────────────────────────────┤
│  共 10 条  [<] [1] [>]    每页 [20] 条                          │
└─────────────────────────────────────────────────────────────────┘
```

---

## 2. 数据字段需求

| 字段名 | 类型 | 说明 | 来源API |
|--------|------|------|---------|
| id | number | 角色ID | GET /api/v1/roles |
| name | string | 角色名称 | GET /api/v1/roles |
| description | string | 描述 | GET /api/v1/roles |
| permission_count | number | 权限数 | GET /api/v1/roles |
| user_count | number | 用户数 | GET /api/v1/roles |

---

## 3. API 依赖汇总

| API | 方法 | 用途 |
|-----|------|------|
| /api/v1/roles | GET | 获取角色列表 |
| /api/v1/roles | POST | 创建角色 |
| /api/v1/roles/:id | PUT | 更新角色 |
| /api/v1/roles/:id | DELETE | 删除角色 |
