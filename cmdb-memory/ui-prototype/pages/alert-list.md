---

## 2. 数据字段需求

| 字段名 | 类型 | 说明 | 来源API |
|--------|------|------|---------|
| id | number | 告警ID | GET /api/v1/alerts |
| title | string | 告警名称 | GET /api/v1/alerts |
| severity | string | 级别 | GET /api/v1/alerts |
| status | string | 状态 | GET /api/v1/alerts |
| fired_at | datetime | 触发时间 | GET /api/v1/alerts |
| resolved_at | datetime | 恢复时间 | GET /api/v1/alerts |
