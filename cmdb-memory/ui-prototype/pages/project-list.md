---

## 2. 组件说明

| 组件 | 类型 | 说明 |
|------|------|------|
| 筛选表单 | BasicForm | 项目名称、负责人、状态 |
| 数据表格 | BasicTable | 项目列表 |
| 新增弹窗 | BasicModal + BasicForm | 新增/编辑项目 |

---

## 3. 数据字段需求

| 字段名 | 类型 | 说明 | 来源API |
|--------|------|------|---------|
| id | number | 项目ID | GET /api/v1/projects |
| name | string | 项目名称 | GET /api/v1/projects |
| code | string | 项目编码 | GET /api/v1/projects |
| owner | string | 负责人 | GET /api/v1/projects |
| status | string | 状态 | GET /api/v1/projects |
| created_at | datetime | 创建时间 | GET /api/v1/projects |

---

## 4. 交互流程

1. 页面加载 → 调用 GET /api/v1/projects
2. 点击新增 → 打开表单弹窗 → POST /api/v1/projects
3. 点击编辑 → 打开表单弹窗 → PUT /api/v1/projects/:id
4. 点击删除 → 确认弹窗 → DELETE /api/v1/projects/:id
5. 点击行 → 跳转详情页

---

## 5. API 依赖汇总

| API | 方法 | 用途 |
|-----|------|------|
| /api/v1/projects | GET | 获取项目列表 |
| /api/v1/projects | POST | 创建项目 |
| /api/v1/projects/:id | PUT | 更新项目 |
| /api/v1/projects/:id | DELETE | 删除项目 |
