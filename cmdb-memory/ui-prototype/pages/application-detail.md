## 2. 数据字段需求

| 字段名 | 类型 | 说明 | 来源API |
|--------|------|------|---------|
| id | number | 应用ID | GET /api/v1/applications/:id |
| name | string | 应用名称 | GET /api/v1/applications/:id |
| code | string | 应用编码 | GET /api/v1/applications/:id |
| project_id | number | 所属项目 | GET /api/v1/applications/:id |
| owner | string | 负责人 | GET /api/v1/applications/:id |
| status | string | 状态 | GET /api/v1/applications/:id |

---

## 3. API 依赖汇总

| API | 方法 | 用途 |
|-----|------|------|
| /api/v1/applications/:id | GET | 获取应用详情 |
| /api/v1/hosts | GET | 获取关联主机 |
| /api/v1/mysql-instances | GET | 获取关联MySQL |
| /api/v1/redis-instances | GET | 获取关联Redis |
