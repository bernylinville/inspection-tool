## 2. 数据字段需求

| 字段名 | 类型 | 说明 | 来源API |
|--------|------|------|---------|
| id | number | 报告ID | GET /api/v1/inspections/:id |
| name | string | 报告名称 | GET /api/v1/inspections/:id |
| type | string | 类型 | GET /api/v1/inspections/:id |
| status | string | 状态 | GET /api/v1/inspections/:id |
| created_at | datetime | 创建时间 | GET /api/v1/inspections/:id |
| duration | string | 执行耗时 | GET /api/v1/inspections/:id |
| host_results | array | 主机巡检结果 | GET /api/v1/inspections/:id |
| alerts | array | 告警汇总 | GET /api/v1/inspections/:id |
