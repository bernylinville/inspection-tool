## 2. 组件说明

| 组件 | 类型 | 说明 |
|------|------|------|
| 统计卡片 | Card + Statistic | 5个统计卡片 |
| 资产分布图 | ECharts Pie | 按类型分布 |
| 告警趋势图 | ECharts Line | 7天告警趋势 |
| 最近告警 | BasicTable | 最近5条告警 |

---

## 3. 数据字段需求

| 字段名 | 类型 | 说明 | 来源API |
|--------|------|------|---------|
| project_count | number | 项目数 | GET /api/v1/projects |
| application_count | number | 应用数 | GET /api/v1/applications |
| host_count | number | 主机数 | GET /api/v1/hosts |
| instance_count | number | 实例数 | 聚合计算 |
| alert_count | number | 告警数 | GET /api/v1/alerts |

---

## 4. API 依赖汇总

| API | 方法 | 用途 |
|-----|------|------|
| /api/v1/projects | GET | 获取项目统计 |
| /api/v1/applications | GET | 获取应用统计 |
| /api/v1/hosts | GET | 获取主机统计 |
| /api/v1/alerts | GET | 获取告警列表 |
