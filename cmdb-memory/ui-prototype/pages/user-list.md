---

## 2. 数据字段需求

| 字段名 | 类型 | 说明 | 来源API |
|--------|------|------|---------|
| id | number | 用户ID | GET /api/v1/users |
| username | string | 用户名 | GET /api/v1/users |
| email | string | 邮箱 | GET /api/v1/users |
| role_ids | array | 角色 | GET /api/v1/users |
| status | string | 状态 | GET /api/v1/users |
| created_at | datetime | 创建时间 | GET /api/v1/users |

---

## 3. API 依赖汇总

| API | 方法 | 用途 |
|-----|------|------|
| /api/v1/users | GET | 获取用户列表 |
| /api/v1/users | POST | 创建用户 |
| /api/v1/users/:id | PUT | 更新用户 |
| /api/v1/users/:id | DELETE | 删除用户 |
