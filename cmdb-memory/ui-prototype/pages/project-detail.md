---

## 2. 组件说明

| 组件 | 类型 | 说明 |
|------|------|------|
| 返回按钮 | Button | 返回列表页 |
| 基本信息 | Description | 项目详情展示 |
| 标签页 | Tabs | 关联应用、关联主机 |
| 关联表格 | BasicTable | 关联数据列表 |

---

## 3. 数据字段需求

| 字段名 | 类型 | 说明 | 来源API |
|--------|------|------|---------|
| id | number | 项目ID | GET /api/v1/projects/:id |
| name | string | 项目名称 | GET /api/v1/projects/:id |
| code | string | 项目编码 | GET /api/v1/projects/:id |
| description | string | 描述 | GET /api/v1/projects/:id |
| owner | string | 负责人 | GET /api/v1/projects/:id |
| status | string | 状态 | GET /api/v1/projects/:id |
| created_at | datetime | 创建时间 | GET /api/v1/projects/:id |

---

## 4. API 依赖汇总

| API | 方法 | 用途 |
|-----|------|------|
| /api/v1/projects/:id | GET | 获取项目详情 |
| /api/v1/applications | GET | 获取关联应用 |
| /api/v1/hosts | GET | 获取关联主机 |
