## 2. 数据字段需求

| 字段名 | 类型 | 说明 | 来源API |
|--------|------|------|---------|
| hostname | string | 主机名 | GET /api/v1/hosts/:id |
| ip | string | IP地址 | GET /api/v1/hosts/:id |
| os | string | 操作系统 | GET /api/v1/hosts/:id |
| os_version | string | 系统版本 | GET /api/v1/hosts/:id |
| kernel_version | string | 内核版本 | GET /api/v1/hosts/:id |
| cpu_cores | number | CPU核数 | GET /api/v1/hosts/:id |
| memory_total | number | 内存总量 | GET /api/v1/hosts/:id |
| cpu_usage | number | CPU使用率 | GET /api/v1/hosts/:id/metrics |
| memory_usage | number | 内存使用率 | GET /api/v1/hosts/:id/metrics |
| disk_usage | number | 磁盘使用率 | GET /api/v1/hosts/:id/metrics |
| load_1m | number | 1分钟负载 | GET /api/v1/hosts/:id/metrics |

---

## 3. API 依赖汇总

| API | 方法 | 用途 |
|-----|------|------|
| /api/v1/hosts/:id | GET | 获取主机详情 |
| /api/v1/hosts/:id/metrics | GET | 获取实时指标 |
| /api/v1/mysql-instances | GET | 获取关联MySQL |
| /api/v1/redis-instances | GET | 获取关联Redis |
